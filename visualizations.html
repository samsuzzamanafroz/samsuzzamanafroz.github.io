Gravitational-Wave Event Catalogue

Since the first detection, GW150914, in September 2015, the LIGO, Virgo and KAGRA detectors have observed nearly four hundred mergers of black holes and neutron stars across four observing runs. This page brings every confident detection in the cumulative Gravitational-Wave Transient Catalog (GWTC), up to the latest GWTC-5.0 release, into one interactive explorer: how many events each run found, how their masses, spins and distances are distributed, and how the population has grown as the detectors became more sensitive.

Filter by observing run, source type, signal strength or probability of astrophysical origin; plot any pair of parameters against each other; and click any event to open its full data release on the Gravitational Wave Open Science Center. The catalogue updates itself live from GWOSC, so new events appear here as soon as they are published.
